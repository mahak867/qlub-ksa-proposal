# qlub-pay — pay-at-table clarity concept (KSA)

> **Unofficial concept — not affiliated with, endorsed by, or built for Qlub.** Independent research and prototype using public information only.

A Saudi-first concept that addresses what diners report in public reviews: confusion between QR pay-at-table and the Qlub+ membership, tips and fees that appear late, stuck payments, and cashback that can't be used.
